# Linux-Log-Collecting-Agent
The aim of this project is to create a lightweight Linux log collecting agent for the following reasons:

1. Increase exposure to Linux fundamentals.
2. Develop experience making architectural and system design decisions.
3. Develop deeper understanding in how traditional log collection systems, like Fluent Bit, work under the hood.
5. Gain experience building, deploying and managing a Linux service.

The project may be further developed down the line into an AI-driven log agent, capable of identifying anomalies
and assisting in diagnosing potential issues. This can be explored as part of a second phase of this project.
